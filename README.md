# Codomax Module 6 – Final Data Science Project

## Customer Churn Analysis & Prediction

An end-to-end Data Science portfolio project combining exploratory data analysis, visualization, feature engineering, supervised machine learning, model evaluation, and churn-risk scoring.

### Dataset
IBM Telco Customer Churn sample dataset:
https://github.com/IBM/telco-customer-churn-on-icp4d

Raw CSV:
https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv

The dataset contains 7,043 customer records and 21 columns, with `Churn` as the target variable.

### Project Workflow
1. Business problem definition
2. Data loading and exploration
3. Data-quality checks
4. Data cleaning
5. Feature engineering
6. Exploratory Data Analysis
7. Data visualization
8. Train/test split
9. Preprocessing and one-hot encoding
10. Logistic Regression
11. Random Forest
12. Gradient Boosting
13. Model evaluation
14. ROC-AUC and confusion matrix
15. Random Forest feature importance
16. Example churn-risk scoring
17. Findings and limitations
